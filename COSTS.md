# Costs and free-tier operation

Target recurring infrastructure spend: **$0/month**, using free plans and local/open-source software. Free tier terms and limits can change; confirm current terms before deployment.

| Service                            | Free path                                                    | Possible charges / limit behavior                                                                                       | Disable or avoid charges                                                                                        |
| ---------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Vercel                             | Hobby includes 1M function invocations, 4 active CPU hours, 360 GB-hours provisioned memory, and 100 GB Fast Data Transfer/month | Hobby is for personal, non-commercial use. Over-limit features pause until the window resets; it does not auto-upgrade. [Plan limits](https://vercel.com/docs/plans/hobby) | Keep the pilot personal/private, monitor usage, and pause deployment on limits. A public/commercial launch needs another eligible free host or an explicitly approved paid plan. |
| Supabase                           | Free includes 500 MB database/project, 50,000 MAU, 5 GB uncached + 5 GB cached egress, 1 GB storage, 500,000 Edge Function invocations; up to 2 active projects | Projects pause after 1 week of inactivity; Free has no automatic backups. Quota exhaustion can interrupt service; Free does not charge overages. [Pricing](https://supabase.com/pricing), [quotas](https://supabase.com/docs/guides/platform/billing-on-supabase) | Keep records/sync frequency modest, monitor usage, export backups manually, resume a paused project; never upgrade automatically |
| Supabase Cron                      | `pg_cron` + `pg_net` job at 15-minute intervals              | Counts toward database/network resources; extension-backed Cron and `pg_net` terms can change. [Cron](https://supabase.com/docs/guides/cron), [scheduling](https://supabase.com/docs/guides/functions/schedule-functions) | Disable the job in Supabase Cron; in-app use remains available                                                   |
| Schoology                          | Official API subject to school/app permissions               | No Daymark charge assumed; access may be unavailable or require approval                                                | Disconnect integration; use manual/CSV assignments                                                              |
| Ollama                             | Local inference, no hosted fee                               | Hardware/electricity cost; model memory and performance limits                                                          | Stop Ollama or disable AI; deterministic planner remains                                                        |
| Hosted OpenAI-compatible inference | Optional free quota if a provider offers one                 | Provider quotas/pricing change and may become paid                                                                      | Leave API key unset; Daymark must not select a paid provider automatically                                      |
| Discord                            | Bot API at no Daymark hosting fee                            | API limits or delivery restrictions; separate hosting would add costs                                                   | Disable Discord channel or revoke bot token                                                                     |
| Browser push                       | Open standards and browser support                           | No per-notification provider charge; browser/OS delivery is not guaranteed                                              | Unsubscribe in settings or browser                                                                              |
| Email                              | Optional Resend Free currently includes 3,000 transactional emails/month and 100/day | Sender/domain verification applies; quota exhaustion stops/rejects sends. Resend paid starts at $20/month and requires an explicit upgrade. [Pricing](https://resend.com/pricing) | Leave `EMAIL_PROVIDER` unset or disable email; do not upgrade the provider account                               |
| SMS                                | Not included in v1                                           | Usually paid per-message                                                                                                | No SMS integration or provider configured                                                                       |

Daymark does not automatically fall back to paid services. If quotas are exhausted, optional synchronization, AI, or delivery may pause and show a setup/error state; core task and calendar data remains in Supabase subject to its own plan availability. The $0 target applies to a personal/private pilot: Vercel Hobby currently restricts use to personal, non-commercial projects. Recheck linked provider terms and limits before a broader launch.
